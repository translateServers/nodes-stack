> 最近更新：2026-07-24

│ 数据集管理                          [+ 新建数据集]        │
├──────────────────────────────────────────────────────────┤
│ [搜索框] [类型▼] [分类▼] [标签▼] [状态▼]    [刷新]      │
├──────────────────────────────────────────────────────────┤
│ 名称       类型    分类     引用数  更新时间    操作      │
│ ──────────────────────────────────────────────────────── │
│ 销售日报    API    销售     3      2026-07-24   编辑/删除 │
│ 库存快照    SQL    库存     5      2026-07-23   编辑/删除 │
│ 静态省份    静态   基础     12     2026-07-20   编辑/删除 │
│ ...                                                       │
├──────────────────────────────────────────────────────────┤
│ 分页                                                      │
└──────────────────────────────────────────────────────────┘
```

### 1.1 关键 UX

- **引用数**：显示被多少组件引用，删除前需确认（参考 GoView 数据池）
- **快速测试**：列表行内"测试"按钮，一键执行并弹出结果
- **分类与标签**：支持按业务域分组，便于大屏项目内组织
- **空状态引导**：首次进入引导用户创建第一个数据集
- **筛选器**：类型 / 分类 / 标签 / 状态多维度筛选，支持组合查询

### 2.1 配置区按类型动态渲染

遵循 Schema 驱动渲染方法论：
- `static` 类型：仅显示静态数据 JSON 编辑器
- `api` 类型：显示连接选择 + 路径 + 方法 + Headers/Params/Body
- `sql` 类型：显示连接选择（仅数据库连接）+ SQL 编辑器
- `websocket` 类型：显示 URL + 协议 + 消息格式（第三阶段实现，第一阶段选择该类型时给出"未支持"提示）

### 2.2 测试结果区

- **原始响应**：后端返回的原始数据，只读 JSON 展示
- **解析后数据**：应用 `dataPath` + `fieldMapping` + `filter` 后的数据
- **字段预览**：维度 / 数值字段映射预览
- **执行信息**：耗时、缓存命中状态、成功/失败状态
- **使用 Mock 开关**：临时切换 Mock 模式测试

## 3. 图形化字段映射编辑器

**核心降低门槛的设计**（Light Chaser 与 GoView 均缺失）：

```
┌──────────────────────────────────────────┐
│ 字段映射                                  │
├──────────────────────────────────────────┤
│ 数据集字段        →   组件字段            │
│ ──────────────────────────────────────── │
│ [province_name ▼] → [dimension ▼]        │
│ [sale_amount   ▼] → [value     ▼]        │
│ [region        ▼] → [未映射     ▼]       │
│                                          │
│ [+ 添加映射]    [自动推断]               │
│                                          │
│ 预览:                                    │
│ { dimension: "浙江省", value: 1234 }     │
└──────────────────────────────────────────┘
```

### 3.1 交互细节

- **自动推断**：从测试响应采样首条数据，按字段名匹配（`name→dimension`、`value→value`）
- **下拉来源**：左侧从数据集字段采样，右侧从组件 schema 声明的字段
- **未映射字段**：可保留或丢弃
- **实时预览**：映射变更后下方预览实时更新

│                                          │

│ 参数名     来源          路径             │

│ region    [URL参数 ▼]   [url.region]     │

│                                          │

│                                          │

```

### 4.1 参数绑定来源

参考 [data-model.md](./data-model.md) 的 `ParamBinding.source` 定义：

| source | 说明 | 示例 |
|---|---|---|
| `component-prop` | 当前组件的 props 字段 | `props.date` |
| `component-data` | 当前组件的已解析数据（用于联动） | `data.selectedRegion` |
| `url-param` | 预览页 URL query | `url.region` |
| `static` | 固定值 | `"2026-07-24"` |
| `trigger` | 蓝图触发器上下文 | `{{trigger.value}}` |

### 4.2 操作按钮

- **管理**：使用 `window.open('/dataset', '_blank')` 在新标签页打开数据集管理页
- **刷新**：重新拉取数据集列表
- **测试数据**：在编辑器内即时测试，显示最近一次测试结果

## 5. 数据源连接管理页

**独立菜单项**，参考 Light Chaser 的数据源管理：

```
┌──────────────────────────────────────────────────────────┐
│ 数据源连接                          [+ 新建连接]         │
├──────────────────────────────────────────────────────────┤
│ 名称        类型       状态      引用数  操作            │
│ ──────────────────────────────────────────────────────── │
│ 销售系统    HTTP API   ●正常    3      编辑/测试/删除    │
│ 库存数据库  MySQL      ●正常    5      编辑/测试/删除    │
│ 日志库      PostgreSQL ●异常    0      编辑/测试/删除    │
└──────────────────────────────────────────────────────────┘
```

### 5.1 关键 UX

- **状态指示灯**：根据 `lastTestResult` 显示绿/红圆点
- **测试按钮**：行内一键测试连接，更新状态
- **密码字段**：编辑时显示为掩码，不回显明文（参考 Light Chaser 的 AES+RSA 加密）
- **引用数**：显示被多少数据集引用，删除前需确认

### 5.2 连接编辑表单

按 `type` 动态渲染：
- `mysql` / `postgres`：host / port / database / username / password / ssl
- `http-api`：baseUrl / defaultHeaders / authType / authConfig

密码字段编辑时为空，留空表示不修改。

## 6. UI 规范遵循

- **shadcn/ui**：管理页与编辑器内表单均使用 shadcn/ui（遵循项目硬约束：编辑器外壳 UI 必须用 shadcn/ui）
- **Schema 驱动渲染**：数据集表单按 `config` 判别联合动态渲染
- **Monaco 编辑器**（新依赖 `monaco-editor`，需显式引入并配置 Vite worker）：SQL / JSON / filter 表达式编辑使用 Monaco；MVP 阶段可降级为 textarea + Zod 校验，Monaco 随 SQL 编辑器（第二阶段）引入
- **响应式布局**：管理页支持窄屏适配，编辑器内表单嵌入属性面板宽度
