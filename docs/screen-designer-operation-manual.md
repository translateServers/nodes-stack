# 大屏设计器操作手册

> 本文档依据《大屏设计器功能点全量清单》（`docs/analysis/screen-designer-feature-inventory.md`）整理，面向**使用大屏设计器制作数据大屏的运营/实施人员**。
> 内容为当前版本的实际可用操作；标注"未实现/已知限制"的项见 §14。

---

## 1. 术语与适用

| 术语 | 含义 |
|---|---|
| 画布 | 中央编辑区域，承载所有组件，支持缩放/平移/参考线 |
| 组件 | 文本、矩形、椭圆、图片、按钮、柱状图等可放置元素 |
| 蓝图（事件蓝图） | 可视化编排"组件事件 → 动作"的逻辑画布（弹层） |
| 数据源 | 组件数据的来源：静态数据 / API 接口 / 数据集 |
| 全局变量 | 可在接口 URL、数据源参数中插值的变量 |

适用入口：左侧导航 **大屏设计器**（路径 `/screen`）。

---

## 2. 快速开始

### 2.1 进入与列表

1. 点击左侧导航 **大屏设计器**，进入大屏列表页（`/screen`）。
2. 列表展示每个项目的 **名称 / 状态 / 缩略图 / 更新时间**，支持按名称关键字搜索与按状态（草稿/已发布/全部）筛选。
3. 行级操作：
   - **编辑**：进入编辑器（始终可用）
   - **预览**：新窗口打开鉴权预览（`/screen-editor-preview/$id`，读取草稿）
   - **公开预览**：新窗口打开匿名预览（`/screen-preview/$id`，读取已发布快照）
   - **发布**：草稿状态可用
   - **导入替换 / 导出 JSON / 删除 / 复制为新项目**

### 2.2 编辑器界面总览

```
┌──────────────────────────────────────────────────────────────┐
│ 顶部菜单（文件 / 编辑 / 视图 / 工具）        ProjectMenubar    │
├──────────┬───────────────────────────────────┬──────────────┤
│ 左面板   │           画布 (Canvas)             │  右面板       │
│ 组件库   │  标尺 ▏参考线 ▏组件 ▏选中框 ▏状态栏 │ 属性/图层/   │
│          │                                    │ 全局变量     │
├──────────┴───────────────────────────────────┴──────────────┤
│ 底部状态栏：Snap ▏Guide ▏交互模式 ▏缩放下拉              StatusBar│
└──────────────────────────────────────────────────────────────┘
```

- **左面板**：组件库（§4）。
- **右面板**：默认显示属性面板；可切到图层、全局变量。
- **工具栏**：选择/抓手/文字/矩形/椭圆/图片/缩放等工具（§3.6）。

### 2.3 三种屏幕模式

按 `F` 在三种模式间循环：

| 模式 | 显示内容 |
|---|---|
| `standard`（默认） | 完整：工具栏 + 侧边栏 + 属性面板 + 状态栏 |
| `withMenu` | 仅顶部菜单 + 画布 |
| `fullscreen` | 仅画布，零 UI 干扰 |

- 按 **`Tab`** 可一键显隐全部面板（`uiVisible` 总闸门，优先级高于屏幕模式）。

## 3. 画布基本操作

### 3.1 缩放

| 操作 | 方式 |
|---|---|
| 放大 | `Ctrl/⌘ + =`（兼容 `Ctrl/⌘ + Shift + =`） |
| 缩小 | `Ctrl/⌘ + -` |
| 适应屏幕 | `Ctrl/⌘ + 0` |
| 滚轮缩放 | 滚轮（Ctrl/Alt/Cmd + 滚轮等价） |
| 缩放工具 | 按 `Z` 后点击画布放大；`Alt + 点击` 缩小（因子 1/1.5） |
| 预设 | 状态栏缩放下拉：`25 / 50 / 75 / 100 / 125 / 150 / 200 %` |

缩放以光标位置为锚点（定点缩放）。

### 3.2 平移

| 操作 | 方式 |
|---|---|
| 临时抓手 | 按住 **`Space`**（松开恢复） |
| 抓手工具 | 按 **`H`** 切换为常驻抓手，拖拽平移 |

> 注：中键拖拽平移**未实现**（文档已描述但无调用点）。

### 3.3 标尺 / 参考线 / 网格 / 对齐

- **标尺**：画布四周 20px 标尺，随缩放在屏幕上保持 ~50px 主刻度间隔。
- **参考线**：从顶部/左侧标尺向画布**拖出**参考线；**双击**参考线删除；拖出容器（>30px）删除。
  - `Ctrl/⌘ + ;` 显隐参考线；视图菜单可锁定/清除参考线。
  - 参考线**不可撤销**，仅显隐状态持久化到本地。
- **网格**：默认关闭、会话级、不持久化（`gridEnabled`/`gridSize`）。
- **智能对齐线**：移动/缩放时自动出现对齐参考（由 Moveable 提供）。
- **边框参考线**：`Ctrl/⌘ + K` 切换。
- **吸附总闸**：状态栏 `Snap` 开关（`snapEnabled`）；参考线/网格/智能对齐均受其约束。

## 4. 组件库与添加组件

### 4.1 打开与浏览

左面板为组件库，支持：

- **搜索**：顶部搜索框按名称过滤。
- **分类**：按类别分组（文本/形状/图表/媒体等）。
- **折叠全部 / 展开全部**。
- **收藏**（★）与**最近使用**：常用组件可收藏；成功添加到画布后自动记入"最近使用"。
- **列表 / 网格**视图切换。

### 4.2 添加到画布

两种方式：

1. **拖拽**：从组件库将卡片拖到画布（拖拽源用自定义格式 `component-type`）。落点按画布坐标换算，自动置于当前最大层级之上；仅当**成功添加**后才会记录"最近使用"。
2. **工具创建**：按 `T`/`R`/`E`/`I` 进入文字/矩形/椭圆/图片工具，在画布点击或拖拽创建。
   - 文字工具点击后进入文本编辑浮层（双击组件也可进入编辑）。
   - 图片工具会触发图片文件选择（png/jpeg/gif/webp/svg），转换为可持久化 data URL。

## 5. 选择与变换

### 5.1 选择

| 操作 | 方式 |
|---|---|
| 单选 | 单击组件 |
| 框选 | 在空白画布拖拽出选区（任意重叠即命中） |
| 加选/减选 | 拖拽框选时按 `Ctrl` 追加 |
| 全选 | `Ctrl/⌘ + A`（自动过滤锁定/隐藏组件） |
| 清空选择 | `Esc`（第一次清 activeGroupId 保留选择，第二次全清） |
| 直接拖拽移交 | 点击未选中组件即开始拖拽（避免先选再拖） |

### 5.2 移动 / 微移

- **拖拽**组件移动；`Alt + 拖拽` 为**复制后移动**（原组件不动）。
- **微移**：方向键 `↑↓←→` 移动 1px；`Shift + 方向键` 移动 10px（不跟随网格，跳过锁定组件）。

### 5.3 缩放与旋转

- **缩放手柄**：选中后显示 8 个方向手柄（4 角 + 4 边）；拖拽缩放。`Alt` 拖拽缩放中心变换。
- **旋转**：旋转手柄拖拽；`Shift` 按住以 **15°** 步进吸附（按手势开始时捕获的 Shift 状态）。

### 5.4 对齐与分布

| 快捷键 | 功能 |
|---|---|
| `Ctrl/⌘ + Alt + L` | 左对齐 |
| `Ctrl/⌘ + Alt + C` | 水平居中 |
| `Ctrl/⌘ + Alt + R` | 右对齐 |
| `Ctrl/⌘ + Alt + T` | 顶对齐 |
| `Ctrl/⌘ + Alt + M` | 垂直居中 |
| `Ctrl/⌘ + Alt + B` | 底对齐 |
| `Ctrl/⌘ + Alt + H` | 水平等距分布 |
| `Ctrl/⌘ + Alt + V` | 垂直等距分布 |

> 对齐/分布**不跳过锁定组件**（已知限制，见 §14）。

### 5.5 分组与层级

| 快捷键 | 功能 |
|---|---|
| `Ctrl/⌘ + G` | 成组 |
| `Ctrl/⌘ + Shift + G` | 解组 |
| `Ctrl/⌘ + ]` | 置顶 |
| `Ctrl/⌘ + [` | 置底 |
| （右键菜单） | 上移一层 / 下移一层 |
| `Ctrl/⌘ + L` / `Ctrl/⌘ + Shift + L` | 锁定 / 解锁选中 |
| `Ctrl/⌘ + H` | 隐藏选中 |

> 多选置顶会**反转选区内相对顺序**（已知限制）。

## 6. 图层管理（图层面板）

右侧"图层"页签打开图层面板：

- **树结构**：顶层组件 + 组（组内含子组件）。
- **重命名**：双击行内联重命名。
- **显隐 / 锁定**：每行图标切换（与画布 `Ctrl/⌘ + H` / `Ctrl/⌘ + L` 同步）。
- **多选**：支持 `Ctrl/⌘` 多选行。
- **拖拽排序**：基于 `@dnd-kit`，需移动 **8px** 才激活；仅可对**顶层组件**平铺重排，**不支持**拖入/拖出组（reparenting）。
- **右键菜单**：置顶/置底/上移/下移/锁定/解锁/隐藏/删除/重命名等。

> 组件数 **> 50** 时图层列表启用虚拟化，虚拟化路径下**拖拽排序完全禁用**，退化为每行置顶/置底按钮。
> 图层内搜索/过滤**未实现**。

## 7. 属性面板

选中组件后，右面板默认显示**属性面板**（由组件 Manifest 的 schema 驱动渲染）：

- **Schema 驱动**：不同组件显示不同的字段控件（文本/数字/颜色/下拉/开关等，见 §24.6）。
- **多选**：选中多个组件时显示多选面板（`MultiSelectPanel`）。
- **画布设置**（`CanvasSettingsFields`）：画布尺寸等画布级属性。
- **组件 JSON 编辑**：通过 Monaco 编辑器直接编辑组件配置（基于 manifest 的 propsSchema 派生 JSON Schema，带自动完成与校验）。入口见 §13。

保存/撤销：属性修改会进入历史（详见 §11）。

## 8. 全局变量

右面板"全局变量"页签可管理全局变量。全局变量用于：

- 接口 URL 插值（预览态传入，编辑器态保留占位符可见）。
- 数据源参数绑定中的 `static` 之外来源（见 §9）。

## 9. 数据绑定

### 9.1 三种数据源

在属性面板配置组件数据源，支持三类：

| 类型 | 说明 |
|---|---|
| `static` | 直接填写静态数据（含 `dataPath` / `fieldMapping`） |
| `api` | 配置接口：仅 **GET**；可设 URL / headers / params / 刷新间隔 |
| `dataset` | 选择数据集 + 参数绑定（走后端代理，不直接访问外部 URL） |

### 9.2 数据集参数绑定

`DatasetConfigForm` 参数来源（MVP）：

- `static`：固定值
- `component-prop`：取组件属性（剥 `props.` 前缀）
- `url-param`：取页面 URL 参数（剥 `url.` 前缀）

> `component-data` 与 `trigger` 两种绑定来源**未实现**（返回 undefined）。

操作：

- 必选数据集；保留 `staticData` / `apiConfig` 以便切回。
- **测试**：`handleTest` 用 mock 执行，成功显示 `成功（{ms}ms）`。
- 跳转数据集管理：`window.open('/dataset')`。

### 9.3 图表数据与逻辑

- `useChartData`：静态数据直接解析；API 数据需上游已拿到原始数据（hook 本身不发起请求）；数据集数据覆盖 `dataPath`。
- **逻辑配置**：排序字段（dimension/value）、方向（asc/desc）、数量上限（limit）。
- **刷新**：API 源支持轮询（`refreshInterval > 0`）；数据集源同样支持轮询。

### 9.4 安全与插值

- API 请求中值为字面量 `[REDACTED]` 的 header **会被移除**（避免用占位值伪造）。
- 全局变量插值仅在预览态生效（编辑器态保留占位符可见）。

### 9.5 动态能力（宿主指标）

若编辑器运行在 `dynamic` 能力档下，组件可声明 `host-metric` 数据能力，使用 `host/xj-metric` 数据源：仅填写**意图**（`metricId` + 绑定），**无 URL/SQL/Token**；实际数据由宿主后端执行。静态档（static）禁用蓝图 `requestApi`、动态数据源等。

## 10. 事件蓝图

### 10.1 打开蓝图

- 在属性面板"事件"区点击，打开**限定到当前组件**的蓝图 Sheet；或从顶部菜单打开全局蓝图。
- 蓝图为独立弹层，拥有自己的快捷键作用域（前缀 `bp-`）。

### 10.2 节点与连线

- **节点类型**：组件节点（component）、条件（condition）、延迟（delay）、注释（comment）、全局（global：pageLoad / interval / navigate / scrollTo）。
- **连线**：从输出锚点拖到输入锚点；带**锚点磁吸**（`use-anchor-snap`）。
- **全局节点**源句柄：`evt:pageLoad` / `evt:interval` / `then` / `else` / `out`；`requestApi` 在 V3 全局节点中被拒绝。

### 10.3 编译与运行

- 蓝图保存后由编译器生成执行计划，运行时执行器（`executor`）按节点顺序执行。
- **模板插值**：节点配置支持模板语法（如 `{{ }}`）引用变量/上游数据。
- **请求脱敏**：涉及 API 的请求在日志/传输中脱敏（`request-api-mask`）。

### 10.4 调试面板

蓝图内提供：

- **执行日志面板**：按执行顺序展示每个节点 success/skipped/failure 及耗时；点击 `onLocateNode` 定位。
- **问题面板**：校验诊断（按级别着色），点击定位节点。
- **搜索面板**：按节点名/类型检索。
- **节点选项 / 节点配置面板**：选中节点后的配置。

### 10.5 蓝图快捷键

蓝图弹层内独立注册（部分）：

| 快捷键 | 功能 |
|---|---|
| `Ctrl/⌘ + S` | 保存 |
| `Ctrl/⌘ + Z` / `Ctrl/⌘ + Shift + Z` | 撤销 / 重做 |
| `Delete` / `Backspace` | 删除选中节点/边 |
| `Ctrl/⌘ + A` | 全选节点 |
| `Ctrl/⌘ + C` / `Ctrl/⌘ + V` / `Ctrl/⌘ + D` | 复制 / 粘贴 / 原地复制节点 |
| `Ctrl/⌘ + =` / `-` / `0` | 放大 / 缩小 / 适配视图 |
| `Space`（按住） | 平移画布 |
| `Esc` | 四层降级（关搜索 → 取消连线 → 清选择 → 关 Sheet） |
| `Ctrl/⌘ + /` | 快捷键帮助 |

### 10.6 定位组件

在蓝图节点上执行"定位"时，主画布对应组件会**闪烁蓝色高亮**（canvas flash overlay），便于在画布中找到目标。

## 11. 历史、撤销与保存

- **撤销 / 重做**：`Ctrl/⌘ + Z` / `Ctrl/⌘ + Shift + Z`（输入框聚焦时让位浏览器原生撤销）。
- **脏标记**：有未保存修改时状态栏/事件提示 `dirty-change`。
- **自动不入历史**：视口（缩放/平移）、选择、参考线、网格、UI 显隐、交互模式等不进入历史。
- **保存冲突**：多人/多端保存时走**三路 rebase**（base/local/remote 递归合并），失败降级全量替换，并弹出保存冲突对话框。

## 12. 预览与发布

### 12.1 预览入口

| 入口 | 路由 | 鉴权 | 数据来源 |
|---|---|---|---|
| 编辑器预览 | `/screen-editor-preview/$id` | 需登录 | 草稿 |
| 公开预览 | `/screen-preview/$id` | 匿名 | 已发布快照 |

二者均经 4 级加载门：注册表加载 → 注册表失败 → 项目加载 → 不存在提示。

### 12.2 发布与交付

- **发布**：将草稿发布为已发布版本（更新 releaseId）。
- **导出 JSON**：浏览器下载项目 JSON。
- **导入替换**：上传 JSON 替换当前项目（经导入控制端口：`prepareImport` → `importProject`）。
- **复制为新项目**：基于当前项目副本创建。
- **快照管理**：本地快照（localStorage）的列表/创建/恢复。

### 12.3 交互模式

状态栏"交互模式"开关在 `design` ↔ `interactive` 间切换（amber 标识 interactive）：
- `design`：设计态，可编辑。
- `interactive`：交互态，模拟最终交互（仍受编辑器约束）。

## 14. 已知限制与提示

以下为当前版本已确认的行为（来自功能清单"已知 bug / 未接线"章节），操作中如遇属预期：

| 现象 | 说明 |
|---|---|
| 中键平移不可用 | 状态机描述了中键手势但无调用点 |
| `Alt + 滚轮` 未反向 | 实际 Alt/Ctrl/Cmd 滚轮等价缩放 |
| 形状创建无正方形/中心约束 | 不读 Shift/Alt |
| 多选置顶反转顺序 | 每次取新 maxZ+1 |
| 对齐/分布包含锁定组件 | locked 组件仍参与 |
| 图层搜索未实现 | 图层面板无过滤框 |
| 虚拟化下图层拖拽禁用 | 组件 > 50 时退化为置顶/置底按钮 |
| 数据集 `component-data`/`trigger` 绑定未实现 | 返 undefined |
| 参考线拖出量维度 bug | 横向参考线纵向拖出与宽度而非高度比较 |
| 数据源 `props.data` 迁移 | 首次经数据层 UI 提交时一次性迁移为静态数据 |
